Debian Caminhos

Um caminho é o endereço de um arquivo ou de uma pasta. Todo comando que mexe em arquivos recebe caminhos. Saber escrevê-los é a diferença entre "funcionou" e "Arquivo ou diretório inexistente".

Você vai aprender
  • A diferença entre caminho absoluto e relativo.
  • Os atalhos ~, ., .. e -.
  • Como escrever nomes com espaço, como "Área de trabalho".
  • Como o Tab escreve caminhos por você.

A ideia: endereço completo ou "a partir daqui"

Pense num endereço de entrega. Você pode dizer o endereço completo ("Rua das Flores, 10, Recife") ou dar uma direção a partir de onde a pessoa está ("a segunda casa à direita"). No terminal é igual:

TipoComeça comExemploFunciona de qualquer pasta?
Absoluto//home/ana/Documentos/notas.txtSim
RelativoQualquer outra coisaDocumentos/notas.txtNão: depende de onde você está

O "onde você está" se chama pasta atual (ou diretório de trabalho). O pwd mostra qual é, e o prompt também mostra, depois dos dois-pontos:

$ pwd
/home/ana

Caminho absoluto

Um caminho absoluto começa na raiz / e desce pasta por pasta até o alvo. Cada / separa uma pasta da próxima.

/
A raiz: o começo de tudo.
home/
Dentro da raiz, a pasta home.
ana/
Dentro de home, a pasta da Ana.
Documentos/notas.txt
Dentro dela, a pasta Documentos e o arquivo.

Como ele não depende da pasta atual, funciona de qualquer lugar. Aqui a Ana está em /etc/apt e mesmo assim acha o arquivo:

$ wc -l /home/ana/Documentos/notas.txt
4 /home/ana/Documentos/notas.txt

Caminho relativo

Um caminho relativo não começa com /. O sistema junta a pasta atual com o que você escreveu. Estando em /home/ana, o caminho Documentos/notas.txt vira /home/ana/Documentos/notas.txt.

$ wc -l Documentos/notas.txt
4 Documentos/notas.txt

O mesmo caminho relativo, digitado em outra pasta, aponta para outro lugar e falha:

$ wc -l Documentos/notas.txt
wc: Documentos/notas.txt: Arquivo ou diretório inexistente      « procurou /etc/apt/Documentos/notas.txt
Quando usar cada um

Relativo é mais curto e prático quando você está perto do arquivo. Absoluto é mais seguro em scripts e em tarefas agendadas, porque não depende de onde o comando foi chamado.

Os atalhos: ~ . .. e -

AtalhoSignificaExemplo
~Sua pasta pessoal (/home/ana)ls ~/Documentos
~joaoA pasta pessoal de outro usuáriols ~joao
.A pasta atual./script.sh
..A pasta de cima (a "mãe")cd ..
-Só no cd: a pasta anteriorcd -

Subindo com ..

Cada .. sobe um nível. Dá para encadear:

cd
Muda de pasta.
../..
Sobe dois níveis: da pasta atual para a mãe, e da mãe para a avó.
$ cd Documentos/projetos
$ pwd
/home/ana/Documentos/projetos
$ cd ../..
$ pwd
/home/ana

Voltando com -

O cd - volta para a pasta em que você estava antes, e mostra para onde foi. É ótimo para alternar entre duas pastas:

$ cd /etc/apt
$ cd -
/home/ana
$ cd -
/etc/apt

Combinando

Os atalhos podem aparecer no meio do caminho. Estando em ~/Documentos/projetos/site, estes dois comandos apontam para o mesmo arquivo:

$ ls ~/frutas.txt ../../../frutas.txt
../../../frutas.txt  /home/ana/frutas.txt

Repare que o ~ virou /home/ana antes de chegar ao ls. Quem faz essa troca é o shell.

Missão: você está em ~/Documentos/projetos/site. Suba até ~/Documentos usando um caminho relativo, com ... Confira com pwd.

Nomes com espaço

O espaço separa as partes de um comando. Por isso um nome como "Área de trabalho" vira três argumentos se for digitado sem cuidado:

$ cd Área de trabalho
bash: cd: número excessivo de argumentos

Há duas formas de dizer ao shell que é um nome só:

FormaExemploObservação
Aspascd 'Área de trabalho'A mais legível; simples ou duplas
Barra invertidacd Área\ de\ trabalhoÉ o que o Tab escreve para você
$ cd 'Área de trabalho'
$ pwd
/home/ana/Área de trabalho

Missão: entre na pasta Área de trabalho. Tente primeiro sem aspas para ver o erro, depois do jeito certo.

Maiúsculas importam

Para o Debian, Documentos e documentos são nomes diferentes:

$ ls documentos
ls: não foi possível acessar 'documentos': Arquivo ou diretório inexistente

Deixe o Tab escrever

Digite o começo de um nome e aperte Tab. Se só houver uma possibilidade, o shell completa sozinho. Se houver várias, aperte Tab duas vezes para ver a lista. O Tab evita erros de digitação e já põe as barras invertidas nos nomes com espaço.

$ cd Do        « aqui você aperta Tab duas vezes
Documentos/  Downloads/
$ cd Doc       « mais uma letra e Tab: vira "cd Documentos/"
O Debian completa até opções

O pacote bash-completion vem instalado no Debian. Com ele, o Tab também completa opções e nomes de pacotes, como em apt install fireTab.

Quando não funciona

"Arquivo ou diretório inexistente" com um caminho que existe

O que aconteceu: quase sempre é um caminho relativo digitado na pasta errada, ou uma maiúscula trocada.

Como resolver: rode pwd para ver onde você está, e ls para ver os nomes exatos. Na dúvida, use o caminho absoluto ou o Tab.

"número excessivo de argumentos" no cd

O que aconteceu: o nome tem espaço e o shell o dividiu.

Como resolver: use aspas: cd "Área de trabalho".

O ~ não funcionou dentro de aspas 
$ ls "~/Documentos"
ls: não foi possível acessar '~/Documentos': Arquivo ou diretório inexistente

O que aconteceu: dentro de aspas o ~ perde o significado especial e vira um til comum.

Como resolver: deixe o til fora das aspas: ls ~/"Documentos", ou use "$HOME/Documentos".

Resumo

  • Absoluto começa com / e funciona de qualquer lugar.
  • Relativo parte da pasta atual (veja com pwd).
  • ~ é sua pasta pessoal, . é a atual, .. é a de cima e cd - volta para a anterior.
  • Nomes com espaço vão entre aspas, e maiúsculas importam.
  • Use o Tab para completar e evitar erros.

Debian pwd e cd

O terminal está sempre "dentro" de alguma pasta. O pwd diz qual é, e o cd leva você para outra. Com esses dois comandos você anda pelo sistema inteiro, sem mouse.

Você vai aprender
  • Descobrir em que pasta você está com pwd.
  • As sete formas mais usadas de cd.
  • Guardar e voltar para pastas com pushd e popd.
  • Entender os erros "Arquivo ou diretório inexistente", "Permissão negada" e "Não é um diretório".

pwd: onde estou?

pwd vem de print working directory, "mostre o diretório de trabalho". Ele escreve o caminho completo da pasta atual.

pwd
Mostra o caminho absoluto da pasta em que o terminal está.
$ pwd
/home/ana

O prompt já dá uma pista: ana@notebook:~$ tem um ~ depois dos dois-pontos, que é o apelido de /home/ana. O pwd mostra o nome por extenso.

pwd -P: o lugar de verdade

Quando você entra numa pasta por um atalho (link simbólico), o pwd mostra o atalho. Com -P (de physical, "físico") ele mostra o destino real. No Debian 13, /bin é um atalho para /usr/bin:

$ cd /bin
$ pwd
/bin
$ pwd -P
/usr/bin

cd: mudar de pasta

cd vem de change directory, "mudar de diretório". Ele não mostra nada quando dá certo: o que muda é o prompt.

cd
O comando que troca a pasta atual.
Documentos
O destino, que pode ser um caminho relativo ou absoluto.
$ cd Documentos
$ pwd
/home/ana/Documentos

Repare que o prompt passou de ~ para ~/Documentos. Para conferir o que existe na pasta nova, use ls.

As formas mais usadas

ComandoVai para
cd DocumentosA pasta Documentos dentro da atual
cd /etc/aptUm caminho absoluto, de qualquer lugar
cd ..A pasta de cima
cd (sozinho)Sua pasta pessoal
cd ~Sua pasta pessoal (o mesmo que cd)
cd -A pasta anterior (e mostra qual é)
cd /A raiz do sistema

Veja uma volta completa:

$ cd /etc/apt
$ cd ..
$ pwd
/etc
$ cd -
/etc/apt
$ cd
$ pwd
/home/ana

Missão: vá até /etc/apt, depois para a sua pasta pessoal, e volte para /etc/apt usando cd -.

pushd e popd: uma pilha de pastas

Quando você precisa visitar uma pasta e depois voltar exatamente para onde estava, o pushd guarda a pasta atual numa pilha e muda de lugar. O popd tira a última da pilha e volta para ela.

pushd
Guarda a pasta atual e vai para outra (de push directory, "empurrar diretório").
/var/log
O destino.
$ pushd /etc
/etc ~/Documentos                « a pilha: atual primeiro
$ pushd /var/log
/var/log /etc ~/Documentos
$ popd
/etc ~/Documentos
$ popd
~/Documentos

O dirs -v mostra a pilha numerada, sem mudar de pasta. É útil em scripts e quando você alterna entre várias pastas de trabalho.

Quando não funciona

"Arquivo ou diretório inexistente" 
$ cd nada
bash: cd: nada: Arquivo ou diretório inexistente

O que aconteceu: não existe pasta com esse nome a partir de onde você está. Pode ser erro de digitação, maiúscula trocada ou pasta errada.

Como resolver: rode ls para ver os nomes certos e use Tab para completar.

"Permissão negada" 
$ cd /root
bash: cd: /root: Permissão negada

O que aconteceu: a pasta existe, mas você não tem permissão para entrar. No Debian, /root e as pastas pessoais dos outros usuários são fechadas.

Como resolver: se for necessário, use su - para virar root (veja root, su e sudo).

"Não é um diretório" 
$ cd .bashrc
bash: cd: .bashrc: Não é um diretório

O que aconteceu: o cd só entra em pastas, e .bashrc é um arquivo.

Como resolver: para ver o conteúdo de um arquivo, use cat ou less (veja cat, less, head, tail).

"número excessivo de argumentos" 
$ cd /etc /tmp
bash: cd: número excessivo de argumentos

O que aconteceu: o cd aceita um destino só. Isso também acontece com nomes que têm espaço, como cd Área de trabalho.

Como resolver: passe um destino só, e coloque entre aspas nomes com espaço.

Missão: provoque de propósito os erros acima (cd nada, cd /root, cd frutas.txt) e termine dentro de /var/log.

Exercícios

1. Voltar para casa

Qual comando, com duas letras, leva você para a sua pasta pessoal de qualquer lugar?

2. Pasta anterior

Complete para voltar à pasta em que você estava antes:

cd

3. O prompt mostra ana@notebook:~/Documentos$. O que o pwd vai responder?

4. Você deu cd /bin. O que pwd -P mostra no Debian 13?

Resumo

  • pwd mostra onde você está; pwd -P ignora os atalhos.
  • cd muda de pasta e não mostra nada quando dá certo; o prompt muda.
  • cd sozinho vai para casa, cd .. sobe, cd - volta.
  • pushd/popd guardam pastas numa pilha.
  • Os erros dizem exatamente o problema: inexistente, permissão ou "não é um diretório".

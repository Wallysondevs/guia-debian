Debian x Ubuntu

O Ubuntu é feito a partir do Debian, então quase tudo o que você sabe continua valendo: o terminal, o apt, o systemctl, as permissões. Mas há diferenças que pegam de surpresa no primeiro dia, a começar pelo sudo, que pode nem existir. Esta página reúne todas elas, conferidas num Debian 13.7 e num Ubuntu 26.04 de verdade.

Você vai aprender
  • As diferenças que mais confundem quem vem do Ubuntu, numa tabela só.
  • Por que o mesmo comando dá mensagens diferentes nos dois sistemas.
  • O equivalente Debian de cada hábito do Ubuntu: snap, netplan, ufw, /var/log/syslog.
  • Onde, neste guia, está a aula completa de cada assunto.

Se você ainda não conhece o Ubuntu, pode pular esta página. Se conhece, ela economiza horas. O guia irmão está em Guia Ubuntu.

E se eu deixar a senha de root em branco na instalação?

Aí o Debian se comporta como o Ubuntu: instala o sudo, coloca o primeiro usuário no grupo sudo e bloqueia o login direto do root. A aula Instalação mostra essa escolha.

Comandos que mudam

Abaixo, o mesmo comando nos dois sistemas. As máquinas são a ana@notebook do Debian e a do Ubuntu, com o título da janela dizendo qual é qual.

Instalar um programa

$ sudo apt install htop
[sudo: authenticate] Senha:
$ sudo apt install htop
bash: sudo: comando não encontrado
$ su -c "apt install htop"
Senha:

No Debian, su -c roda um comando como root e volta. Para um shell inteiro de root, su - e, no fim, exit.

Reiniciar a máquina

$ reboot
$ reboot
bash: reboot: comando não encontrado     « fora do PATH da ana
$ su -c reboot

Criar uma pasta que já existe

$ mkdir fotos
mkdir: fotos: Arquivo existe
$ mkdir fotos
mkdir: cannot create directory ‘fotos’: Arquivo existe

Mesmo erro, textos diferentes: o Ubuntu usa o mkdir em Rust e o Debian, o do GNU (que deixa o começo da frase sem traduzir).

Ver o log do sistema

$ tail -n 2 /var/log/syslog
$ tail -n 2 /var/log/syslog
tail: não foi possível abrir '/var/log/syslog' para leitura: Arquivo ou diretório inexistente
$ journalctl -n 2
Hint: You are currently not seeing messages from other users and the system.
      Users in groups 'adm', 'systemd-journal' can see all messages.
      Pass -q to turn off this notice.

Para ver os logs de tudo, rode o journalctl como root ou coloque a ana no grupo adm.

Listar arquivos

$ ls -l frutas.txt
-rw-rw-r-- 1 ana ana 47 Oct 14 16:05 frutas.txt
$ ls -l frutas.txt
-rw-rw-r-- 1 ana ana 47 out 14 16:05 frutas.txt
$ ll
bash: ll: comando não encontrado

Abrir o firewall para o SSH

#> ufw allow ssh
#> ufw allow ssh
bash: ufw: comando não encontrado

No Debian, o caminho nativo é o nftables: você escreve as regras em /etc/nftables.conf e liga o serviço, que vem desligado. O ufw pode ser instalado se você preferir o jeito do Ubuntu.

O que continua igual

  • apt, dpkg e os pacotes .deb (o Ubuntu herdou tudo do Debian).
  • systemctl, journalctl e o systemd.
  • Bash, permissões, grep, find, pipes e redirecionamento.
  • SSH, ip, ping, cron.
  • Os atalhos do GNOME e o terminal de emergência (Ctrl+Alt+F3).

Resumo

  • Com senha de root, o Debian não tem sudo: use su - ou su -c "comando".
  • O PATH da ana não tem /sbin, por isso reboot e adduser não são encontrados.
  • Sem snap, sem netplan, sem ufw, sem /var/log/syslog: use Flatpak, ifupdown, nftables e journalctl.
  • As mensagens dos comandos básicos vêm do GNU, em português, e o ls segue o idioma.
  • O resto (apt, systemd, bash) é o mesmo que você já conhece.

Debian Atalhos de Teclado

Uma página para consultar e imprimir: os atalhos do terminal, da área de trabalho GNOME, dos programas que você mais vai usar e, principalmente, os de emergência, para quando tudo trava. Os atalhos do GNOME e do terminal foram conferidos nas configurações padrão do Debian 13.

Como ler

Ctrl+C quer dizer "segure Ctrl e aperte C". Super é a tecla com o logotipo do Windows. Ctrl+B D, no tmux, quer dizer "aperte Ctrl+B, solte, e depois aperte D".

SysRq no Debian: o valor 438

As "teclas mágicas" falam direto com o kernel. O Debian liga uma parte delas com kernel.sysrq = 438 (arquivo /usr/lib/sysctl.d/50-default.conf). O número é uma soma de permissões:

Tecla (com Alt+SysRq)FazNo Debian (438)
RTira o teclado do controle da interface gráficaFunciona (valor 4)
EPede para os processos fecharem (sinal TERM)Bloqueada (valor 64 não incluso)
IMata os processos (sinal KILL)Bloqueada
SGrava nos discos o que está na memóriaFunciona (valor 16)
URemonta os discos como só leituraFunciona (valor 32)
BReinicia na horaFunciona (valor 128)
$ cat /proc/sys/kernel/sysrq
438

A tecla SysRq costuma ser a mesma do PrtSc; em notebooks pode precisar de Fn. Aperte as letras devagar, com um ou dois segundos entre elas. No Ubuntu o padrão é 176, que bloqueia também o R.

Ctrl+Alt+T não abre o terminal no Debian

Esse atalho é uma configuração do Ubuntu. No GNOME do Debian ele não existe: a lista de atalhos do GNOME 48 (pacote gnome-settings-daemon-common) não tem nenhuma tecla para o terminal. Para abrir o terminal, aperte Super e digite "terminal". Se quiser o atalho, crie em Configurações → Teclado → Atalhos de teclado → Atalhos personalizados, com o comando gnome-terminal e a tecla Ctrl+Alt+T.

Resumo

  • Travou? Ctrl+Alt+F3; se nada responder, Alt+SysRq+R S U B.
  • No terminal, copiar e colar levam Shift: Ctrl+Shift+C / V.
  • Tab completa, Ctrl+R busca no histórico.
  • No Debian não há Ctrl+Alt+T pronto; crie o atalho nas Configurações se quiser.

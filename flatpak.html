Debian Flatpak

O Debian estável prefere programas testados a programas novos: a versão de cada pacote fica "congelada" durante os cerca de dois anos de vida da versão. Quando você quer a versão mais recente de um aplicativo de desktop (um editor de imagens, um player, um app de chat), o caminho mais usado no Debian é o Flatpak, com a loja Flathub.

Você vai aprender
  • O que é o Flatpak e por que ele convive com o apt.
  • Instalar o flatpak e adicionar o Flathub.
  • Procurar, instalar, rodar, atualizar e remover aplicativos.
  • Quando usar Flatpak e quando usar o apt.

O que é o Flatpak

Um aplicativo Flatpak vem com quase tudo de que precisa dentro dele, e roda isolado do resto do sistema (numa "caixa de areia", a sandbox). As partes comuns entre aplicativos, como as bibliotecas do GNOME ou do KDE, ficam em pacotes compartilhados chamados runtimes.

apt (pacotes .deb)Flatpak
De onde vemRepositórios do DebianFlathub (ou outros remotos)
VersãoA do Debian estável (testada, às vezes antiga)Geralmente a mais nova
Quem empacotaMantenedores do DebianOs próprios autores ou a comunidade do Flathub
Espaço em discoMenor (bibliotecas compartilhadas com o sistema)Maior (o primeiro app baixa um runtime de centenas de MB)
IsolamentoNenhumRoda numa sandbox com permissões
Bom paraSistema, ferramentas de terminal, servidoresAplicativos de desktop
E o Snap?

No Ubuntu, a loja padrão de aplicativos usa Snap. O Debian não usa Snap por padrão (o pacote snapd existe, mas é pouco usado). Na comunidade Debian, o caminho comum para apps recentes é o Flatpak.

Instalar o Flatpak e adicionar o Flathub

São dois passos, feitos uma vez só, como root:

  1. Instale o programa flatpak. 
    $ su -
Senha:
#> apt install flatpak
  2. Adicione o Flathub, o repositório (chamado de remoto) com os aplicativos.
    flatpak remote-add
    Adiciona um remoto.
    --if-not-exists
    Não reclama se ele já estiver adicionado.
    flathub
    O nome que você dá ao remoto.
    https://dl.flathub.org/repo/flathub.flatpakrepo
    O endereço oficial do Flathub.
    #> flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
#> flatpak remotes
Nome    Opções
flathub system

system quer dizer que o Flathub vale para todos os usuários da máquina.

Ver os apps do Flatpak na loja gráfica

Se você usa o GNOME, instale também o complemento que faz o aplicativo Programas (GNOME Software) mostrar os apps do Flathub. No KDE, o equivalente é o do Discover:

#> apt install gnome-software-plugin-flatpak

No KDE Plasma, o pacote é plasma-discover-backend-flatpak.

Saia e entre de novo

Depois de instalar o Flatpak pela primeira vez, saia da sessão e entre de novo (ou reinicie). Só assim os ícones dos apps instalados aparecem no menu.

Procurar, instalar e rodar

Cada app tem um ID no formato de endereço invertido, como org.gnome.Calculator. É ele que você usa nos comandos.

flatpak search
Procura no Flathub.
calculator
O termo. Funciona melhor em inglês, porque os nomes e descrições estão em inglês.
$ flatpak search calculator
Nome          Descrição                         ID de aplicativo          Versão   Ramo    Remotos
Calculadora   Perform arithmetic, scientific…   org.gnome.Calculator      48.1     stable  flathub
Qalculate!    Powerful and easy to use…         io.github.Qalculate       5.5.0    stable  flathub

Os resultados e as versões mudam com o tempo: a lista acima é um exemplo do formato. Os títulos das colunas são os do Flatpak do Debian em português. Se nada combinar, a resposta é Nenhuma correspondência localizada.

Para instalar, diga o remoto e o ID:

flatpak install
Instala um aplicativo.
flathub
De qual remoto.
org.gnome.Calculator
O ID do app.
#> flatpak install flathub org.gnome.Calculator

O Flatpak mostra uma tabela com o que vai baixar (o app e, na primeira vez, o runtime, que pode ter algumas centenas de MB) e pergunta Prosseguir com essas alterações para a instalação da sistema? [Y/n]. Ao final, aparece Instalação concluída. e o app vai para o menu. Pelo terminal, ele roda assim:

$ flatpak run org.gnome.Calculator
Instalar só para você, sem root

Com --user, o Flatpak instala na sua pasta pessoal e não pede o administrador: flatpak install --user flathub org.gnome.Calculator. Para isso, o remoto também precisa existir para o usuário: flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo.

Listar, atualizar e remover

ComandoO que faz
flatpak listLista apps e runtimes instalados
flatpak list --appSó os aplicativos
flatpak updateAtualiza todos os apps e runtimes (o apt upgrade não atualiza Flatpaks)
flatpak info IDDetalhes de um app instalado
flatpak uninstall IDRemove o app
flatpak uninstall --unusedRemove runtimes que nenhum app usa mais
flatpak override --user --nofilesystem=home IDTira uma permissão de um app
Atualize os dois mundos

Programas do apt e do Flatpak se atualizam separadamente. Na sua rotina, rode apt update && apt upgrade e flatpak update. O aplicativo Programas do GNOME cuida dos dois pela interface.

Flatpak ou apt?

SituaçãoUse
Ferramentas de terminal (htop, git, curl)apt
Servidores e serviços (nginx, ssh, banco de dados)apt
App de desktop que você quer na versão mais novaFlatpak
App que não existe nos repositórios do DebianFlatpak
Computador com pouco espaço em discoapt

Outra opção para versões mais novas sem sair do apt são os backports.

Quando não funciona

"bash: flatpak: comando não encontrado"

O que aconteceu: o Flatpak não vem instalado no Debian.

Como resolver: como root, apt install flatpak.

"Nenhum remoto" ou a busca não acha nada

O que aconteceu: o Flathub ainda não foi adicionado.

Como resolver: rode o flatpak remote-add desta aula e confira com flatpak remotes.

"Nada corresponde a … no remoto flathub"

O que aconteceu: o ID está escrito errado, ou o app não existe no Flathub.

Como resolver: confira o ID exato com flatpak search; maiúsculas e minúsculas contam (org.gnome.Calculator).

Instalei, mas o app não aparece no menu

O que aconteceu: a sessão ainda não carregou a pasta de atalhos do Flatpak.

Como resolver: saia e entre de novo. Enquanto isso, rode com flatpak run ID.

O app não consegue abrir arquivos de uma pasta

O que aconteceu: a sandbox limita o acesso do app a pastas.

Como resolver: veja as permissões com flatpak info --show-permissions ID e libere uma pasta com flatpak override --user --filesystem=~/Documentos ID. O app Flatseal (no Flathub) faz isso pela interface.

Resumo

  • Flatpak traz apps de desktop recentes, isolados numa sandbox.
  • Instale com apt install flatpak e adicione o Flathub com flatpak remote-add.
  • flatpak install flathub ID, flatpak run ID, flatpak update, flatpak uninstall ID.
  • Use o apt para o sistema e ferramentas de terminal; Flatpak para apps de desktop novos.

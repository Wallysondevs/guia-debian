Debian apt

No Debian, os programas vêm em pacotes, baixados dos servidores do projeto. O apt (de Advanced Package Tool) é a ferramenta que procura, instala, atualiza e remove esses pacotes. Ele foi criado no próprio Debian e depois adotado pelo Ubuntu e por dezenas de outras distribuições.

Você vai aprender
  • O que são pacotes, repositórios e dependências.
  • Por que, no Debian, o apt é usado como root (com su -).
  • A diferença entre update, upgrade e full-upgrade.
  • Procurar, instalar, remover e limpar pacotes.
  • As mensagens reais do apt 3 e o que fazer quando ele reclama.

Pacotes, repositórios e dependências

  • Um pacote é um arquivo .deb com o programa e as informações de instalação.
  • Um repositório é um servidor com milhares de pacotes. O Debian usa deb.debian.org (pacotes) e security.debian.org (correções de segurança). A lista fica em /etc/apt/sources.list (veja Repositórios).
  • Uma dependência é outro pacote de que o programa precisa. O apt as instala sozinho.

Quem pode usar o apt

Instalar e remover programas muda o sistema inteiro, então exige o administrador. Como a ana, o apt avisa:

$ apt install htop
Erro: Não foi possível abrir arquivo de trava /var/lib/dpkg/lock-frontend - open (13: Permissão negada)
Erro: Não é possível adquirir a trava da interface do dpkg (/var/lib/dpkg/lock-frontend), você é root?

Por isso, nesta aula, os comandos rodam como root, depois de um su - (prompt #). Se o seu Debian tem sudo liberado, escreva sudo antes de cada comando. Veja root, su e sudo.

$ su -
Senha:
#>
Comandos que não precisam de root

apt search, apt show, apt list e apt policy só consultam informações e funcionam também como ana.

update e upgrade: não é a mesma coisa

apt
O gerenciador de pacotes.
update
Baixa a lista de pacotes e versões disponíveis. Não instala nada.
#> apt update
Atingido:1 http://security.debian.org/debian-security trixie-security InRelease
Atingido:2 http://deb.debian.org/debian trixie InRelease
Atingido:3 http://deb.debian.org/debian trixie-updates InRelease
Todos os pacotes estão atualizados.

Cada linha é um repositório consultado. Atingido quer dizer que a lista não mudou desde a última vez; Obter quer dizer que uma lista nova foi baixada. A última linha diz se há algo para atualizar; quando há, aparece algo como 3 pacotes podem ser atualizados. Execute 'apt list --upgradable' para vê-los.

apt
O gerenciador de pacotes.
upgrade
Instala as versões novas dos pacotes que já estão instalados.
#> apt upgrade
Resumo:
  Atualizando: 0, Instalando: 0, Removendo: 0, Não atualizando: 0

Antes do resumo, o apt mostra linhas de progresso como Lendo listas de pacotes... e Calculando atualização...; elas foram omitidas aqui. Zero em tudo quer dizer que não havia nada para atualizar.

A ordem certa é sempre primeiro update, depois upgrade: o upgrade só sabe das versões novas que o update baixou.

ComandoO que faz
apt updateAtualiza a lista do que existe nos repositórios
apt upgradeAtualiza os pacotes instalados, sem remover nenhum
apt full-upgradeAtualiza mesmo que precise instalar ou remover pacotes para resolver dependências
apt list --upgradableMostra o que tem atualização
Rotina recomendada

apt update && apt upgrade. O && só roda o segundo comando se o primeiro der certo. O full-upgrade fica para quando o upgrade diz que "não atualizou" alguns pacotes, e para a troca de versão do Debian (veja Atualizar a Versão do Debian).

Achar o nome do pacote

O nome do pacote nem sempre é o nome do programa. Procure com search, que olha o nome e a descrição:

$ apt search htop
Ordenando...
Pesquisa de texto completo...
aha/stable 0.5.1-3 amd64
  ANSI color to HTML converter

bashtop/stable 0.9.25-1 all
  Resource monitor that shows usage and stats

htop/stable 3.4.1-5 amd64
  visualizador de processos interativo

Cada resultado mostra nome/origem versão arquitetura e a descrição. A origem stable é a versão estável do Debian (a 13, "trixie"). Algumas descrições estão traduzidas, outras não.

Para ver os detalhes de um pacote, use show:

$ apt show htop
Package: htop
Version: 3.4.1-5
Priority: optional
Section: utils
Maintainer: Daniel Lange <DLange@debian.org>
Installed-Size: 434 kB
Depends: libc6 (>= 2.38), libncursesw6 (>= 6), libtinfo6 (>= 6)
Suggests: lm-sensors, lsof, strace
Homepage: https://htop.dev/
Download-Size: 171 kB
APT-Sources: http://deb.debian.org/debian trixie/main amd64 Packages
Description: visualizador de processos interativo
 Htop é um visualizador de processos baseado em ncurses similar ao top, mas
 permite percorrer a lista verticalmente e horizontalmente para ver

Os campos importantes: Version (versão), Depends (dependências), Installed-Size (espaço depois de instalado) e APT-Sources (de qual repositório vem).

O aviso "does not have a stable CLI interface"

Se você mandar a saída do apt para outro comando ou arquivo, ele avisa:

$ apt search htop | head -3

WARNING: apt does not have a stable CLI interface. Use with caution in scripts.

Ordenando...

Não é erro. O apt foi feito para pessoas, e o formato da saída pode mudar entre versões. Em scripts, use os comandos mais antigos apt-get e apt-cache, que mantêm o formato estável.

apt
O gerenciador.
install
Instalar.
htop
Um ou mais nomes de pacote, separados por espaço.
#> apt install htop

Resumo:

  Tamanho de download: 171 kB

Obter:1 http://deb.debian.org/debian trixie/main amd64 htop amd64 3.4.1-5 [171 kB]

O apt mostra antes o que vai fazer (Instalando, Pacotes sugeridos, Resumo). Quando a instalação traz outros pacotes junto, ele pergunta Você quer continuar? [S/n]: Enter ou S confirma, n cancela. Os "sugeridos" não são instalados; são só ideias de pacotes que combinam. Se o pacote já estiver instalado, a resposta é htop já é a versão mais nova (3.4.1-5).

Remover: remove, purge e autoremove

ComandoRemove o programa?Remove as configurações do sistema?
apt remove htopSimNão (ficam em /etc, se houver)
apt purge htopSimSim
apt autoremoveRemove dependências que ninguém mais usa—
#> apt remove htop
REMOVENDO:
  htop

Resumo:
  Atualizando: 0, Instalando: 0, Removendo: 1, Não atualizando: 0
  Espaço liberado: 434 kB

Você quer continuar? [S/n] S
(Lendo banco de dados ... 33975 arquivos e diretórios atualmente instalados).
Removendo htop (3.4.1-5) ...
Processando gatilhos para man-db (2.13.1-1) ...

Em maiúsculas, REMOVENDO chama a atenção de propósito: confira a lista antes de confirmar. Se aparecerem pacotes que você não esperava (por exemplo, o ambiente gráfico inteiro), responda n.

Atenção com o -y na remoção

apt remove -y não mostra a pergunta. Um nome errado pode levar junto dezenas de pacotes. Na dúvida, rode sem -y e leia a lista.

Outras tarefas úteis

De onde vem e qual versão: apt policy

$ apt policy htop
htop:
  Instalado: (nenhum)
  Candidato: 3.4.1-5
  Tabela de versão:
     3.4.1-5 500
        500 http://deb.debian.org/debian trixie/main amd64 Packages

Instalado é a versão que você tem; Candidato, a que o apt instalaria. O número 500 é a prioridade do repositório; ele importa quando você usa backports.

Listar

$ apt list --installed | wc -l
307

Limpar o cache

Os .deb baixados ficam em /var/cache/apt/archives/. apt clean apaga todos; apt autoclean apaga só os que não estão mais nos repositórios.

Quando não funciona

"você é root?" 
$ apt install htop
Erro: Não foi possível abrir arquivo de trava /var/lib/dpkg/lock-frontend - open (13: Permissão negada)
Erro: Não é possível adquirir a trava da interface do dpkg (/var/lib/dpkg/lock-frontend), você é root?

O que aconteceu: você rodou como usuário comum.

Como resolver: su - e repita (ou sudo apt install htop, se tiver sudo).

"Aguardando por trava de cache" 
#> apt install htop
Aguardando por trava de cache: Não foi possível obter a trava /var/lib/dpkg/lock-frontend. Ela está sendo mantida pelo processo 9748 (apt-get)... 36s

O que aconteceu: outro programa está instalando pacotes (outro terminal, a atualização automática ou o aplicativo Programas). Só um pode mexer nos pacotes por vez.

Como resolver: espere; o apt continua sozinho quando a trava for liberada. Veja quem é com ps -p 9748 -o pid,etime,args. Não apague os arquivos de trava.

"Não é possível encontrar o pacote" 
#> apt install pacoteinexistente
Erro: Não é possível encontrar o pacote pacoteinexistente

O que aconteceu: o nome está errado, a lista está desatualizada, ou o pacote está num componente que você não ativou (como contrib ou non-free).

Como resolver: apt update, depois apt search parte-do-nome. Se for software não livre, veja Repositórios.

"dpkg foi interrompido"

O que aconteceu: uma instalação anterior parou no meio (queda de energia, terminal fechado).

Como resolver: como root, dpkg --configure -a e depois apt -f install.

Resumo

  • O apt instala, atualiza e remove pacotes; no Debian, use-o como root (su -).
  • update baixa a lista; upgrade instala as atualizações.
  • remove mantém configurações; purge apaga tudo; autoremove limpa órfãos.
  • search, show e policy funcionam sem root.
  • Leia o resumo antes de confirmar, principalmente a lista REMOVENDO.

Debian dpkg e .deb

O dpkg (de Debian package) é o programa que de fato instala, remove e registra pacotes no Debian. O apt fica por cima dele: busca nos repositórios, resolve dependências e chama o dpkg. Você vai usar o dpkg direto para instalar um .deb baixado, para descobrir de onde veio um arquivo e para consertar uma instalação que parou no meio.

Você vai aprender
  • O que tem dentro de um .deb e como espiar antes de instalar.
  • Por que preferir apt install ./arquivo.deb ao dpkg -i.
  • A consultar o sistema: dpkg -l, -L, -S e -s, lendo cada coluna.
  • A consertar dependências faltando e instalações interrompidas.
  • A refazer as perguntas de um pacote com dpkg-reconfigure.

Antes do comando: o que é um pacote

Um arquivo .deb é um pacote: os arquivos do programa, mais uma "ficha" (control) com nome, versão, de quais outros pacotes ele depende e scripts para rodar na instalação. Repare no nome do arquivo:

hello
Nome do pacote.
_2.10-5
Versão do programa (2.10) e revisão do pacote no Debian (5).
_amd64
Arquitetura: processadores de 64 bits (Intel/AMD). all serve para qualquer uma.
.deb
Formato de pacote do Debian.
FerramentaTrabalha comResolve dependências?
dpkgUm arquivo .deb e o registro do que está instaladoNão: só avisa que faltam
aptRepositórios (e .deb locais com ./)Sim: baixa o que faltar

Espiar um .deb antes de instalar

Ler a ficha não precisa de root. É um bom hábito com qualquer .deb baixado da internet:

$ dpkg -I hello_2.10-5_amd64.deb
 novo pacote Debian, versão 2.0.
 tamanho 53228 bytes: arquivo de controle= 1872 bytes.
     757 bytes,    20 linhas      control
    3601 bytes,    49 linhas      md5sums
 Package: hello
 Version: 2.10-5
 Architecture: amd64
 Maintainer: Santiago Vila <sanvila@debian.org>
 Installed-Size: 280
 Depends: libc6 (>= 2.38)                « do que ele precisa
 Section: devel
 Priority: optional
 Homepage: https://www.gnu.org/software/hello/
 Description: example package based on GNU hello

O -I (info) mostra a ficha. O -c (contents) lista os arquivos que serão instalados, e onde:

$ dpkg -c hello_2.10-5_amd64.deb | head -4
drwxr-xr-x root/root         0 2025-04-16 06:50 ./
drwxr-xr-x root/root         0 2025-04-16 06:50 ./usr/
drwxr-xr-x root/root         0 2025-04-16 06:50 ./usr/bin/
-rwxr-xr-x root/root     35544 2025-04-16 06:50 ./usr/bin/hello

Para ver só alguns campos, o dpkg-deb -f é mais direto:

$ dpkg-deb -f hello_2.10-5_amd64.deb Package Version Depends
Package: hello
Version: 2.10-5
Depends: libc6 (>= 2.38)

Instalar um .deb baixado

Instalar exige root. No Debian, isso quer dizer su - primeiro (o dpkg de usuário comum responde dpkg: erro: a operação solicitada requer privilégios de superusuário).

Forma recomendada: apt install ./arquivo.deb

apt install
Instalar, como sempre.
./hello_2.10-5_amd64.deb
O caminho do arquivo. O ./ (ou qualquer /) é o que avisa o apt de que é um arquivo, e não um nome de pacote do repositório.
#> cd /tmp
#> apt install ./hello_2.10-5_amd64.deb
…
Instalando:
  hello

Resumo:
  Atualizando: 0, Instalando: 1, Removendo: 0, Não atualizando: 0
…
#> hello
Olá, mundo!

A vantagem: se o .deb precisar de outros pacotes, o apt os baixa dos repositórios na mesma operação.

A forma antiga: dpkg -i

#> dpkg -i hello_2.10-5_amd64.deb

Processando gatilhos para man-db (2.13.1-1) ...

Qual usar?

SituaçãoComando
Você baixou um .deb de um siteapt install ./arquivo.deb
O .deb não tem dependências, ou você já sabe que estão instaladasdpkg -i arquivo.deb funciona igual
Usou dpkg -i e deu "problemas de dependência"apt -f install
O programa está no repositório do DebianNem baixe o .deb: apt install nome
.deb de qualquer site é risco

Um .deb roda scripts como root na instalação: pode fazer qualquer coisa com a máquina. Instale só de fontes em que você confia. E um .deb feito para o Ubuntu nem sempre combina com as bibliotecas do Debian; prefira o pacote "para Debian" quando o site oferecer.

Remover com o dpkg

#> dpkg -r hello
(Lendo banco de dados ... 40922 arquivos e diretórios atualmente instalados).
Removendo hello (2.10-5) ...
Processando gatilhos para man-db (2.13.1-1) ...
#> dpkg -P fortune-mod                  « P de purge: remove também as configurações
(Lendo banco de dados ... 40787 arquivos e diretórios atualmente instalados).
Removendo fortune-mod (1:1.99.1-9) ...

Na prática, prefira apt remove e apt purge (veja apt): o apt avisa se outro pacote depende do que você vai tirar, e depois o apt autoremove limpa as dependências que sobraram.

Consertar uma instalação interrompida

Se o computador desligou, a conexão caiu ou alguém apertou Ctrl+C no meio de uma instalação, o próximo apt avisa:

#> apt install htop
Erro: dpkg was interrupted, you must manually run 'dpkg --configure -a' to correct the problem.

A mensagem não tem tradução, mas diz exatamente o que fazer:

dpkg
O programa.
--configure
Termina a configuração de pacotes que ficaram pela metade.
-a
De todos os pacotes nessa situação (all).
#> dpkg --configure -a
#> apt -f install                     « se ainda houver dependências faltando

Para conferir se sobrou algo quebrado, use dpkg --audit: se não mostrar nada, está tudo certo.

Refazer as perguntas de um pacote: debconf

Alguns pacotes fazem perguntas na instalação: o fuso horário, o idioma, o layout do teclado. As respostas ficam guardadas no debconf, o banco de perguntas do Debian. Para ver o que foi respondido:

#> debconf-show tzdata
* tzdata/Zones/America: Sao_Paulo         « o * marca as perguntas já respondidas
* tzdata/Areas: America
  tzdata/Zones/Europe:
  …

Para responder de novo, o dpkg-reconfigure reabre as telas do pacote:

Comando (como root)Para quê
dpkg-reconfigure tzdataTrocar o fuso horário
dpkg-reconfigure localesGerar outros idiomas e escolher o padrão
dpkg-reconfigure keyboard-configurationTrocar o layout do teclado do console
dpkg-reconfigure console-setupFonte e tamanho do texto no console

Lembre: o dpkg-reconfigure fica em /usr/sbin, então a ana só o encontra depois de su -.

Quando não funciona

"requer privilégios de superusuário" 
$ dpkg -i hello_2.10-5_amd64.deb
dpkg: erro: a operação solicitada requer privilégios de superusuário

Como resolver: su -, vá até a pasta do arquivo (depois do su - você está em /root) e rode de novo, ou use o caminho completo: apt install /home/ana/Downloads/hello_2.10-5_amd64.deb.

"trava da interface do dpkg foi travado pelo processo…" 
#> dpkg -i hello_2.10-5_amd64.deb
dpkg: erro: trava da interface do dpkg foi travado pelo processo /usr/bin/apt-get com pid 9748
Observação: remover o arquivo de trava é sempre errado, podendo danificar a área
travada e todo o sistema. Veja <https://wiki.debian.org/Teams/Dpkg/FAQ#db-lock>.

O que aconteceu: outro programa (um apt em outro terminal, ou as atualizações automáticas) está instalando algo agora. Só um pode mexer nos pacotes por vez.

Como resolver: espere ele terminar. Veja quem é com ps -p 9748 -o pid,etime,cmd. Como o próprio aviso diz, nunca apague o arquivo de trava.

"não é um arquivo no formato Debian" 
#> dpkg -i programa.deb
dpkg-deb: erro: 'programa.deb' não é um arquivo no formato Debian
dpkg: erro processando o arquivo programa.deb (--install):
 o subprocesso dpkg-deb --control retornou estado de saída de erro 2

O que aconteceu: o arquivo não é um .deb de verdade. Quase sempre o download falhou e o arquivo é uma página de erro HTML, ou ficou incompleto.

Como resolver: confira com file programa.deb e baixe de novo.

"pacote não está instalado" 
$ dpkg -s naoexiste
dpkg-query: pacote 'naoexiste' não está instalado e não há informações disponíveis
Use dpkg --info (= dpkg-deb --info) para examinar arquivos de pacote.
$ dpkg -S /etc/xyz
dpkg-query: nenhum caminho encontrado correspondente ao padrão /etc/xyz

O que aconteceu: o dpkg só sabe do que está instalado. Para pacotes que você ainda não tem, use apt show nome ou apt search palavra. E um arquivo que nenhum pacote instalou (criado por você ou por um programa) não aparece no dpkg -S.

Resumo

  • O dpkg instala e registra pacotes; o apt fica por cima e resolve dependências.
  • Espie antes: dpkg -I (ficha) e dpkg -c (arquivos).
  • Instale .deb baixados com apt install ./arquivo.deb; depois de um dpkg -i com erro, apt -f install.
  • Consultas: -l (lista), -L (arquivos), -S (quem instalou), -s (ficha).
  • Instalação interrompida: dpkg --configure -a. Trava ocupada: espere; nunca apague o arquivo de trava.
  • dpkg-reconfigure refaz as perguntas de pacotes como tzdata e locales.

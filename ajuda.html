Debian Obtendo Ajuda

Ninguém decora as opções de todos os comandos. Quem usa Linux há anos consulta a ajuda o tempo todo, e o Debian traz muita ajuda instalada, boa parte em português. Nesta aula você aprende onde procurar: o manual (man), o --help, a busca por assunto, os resumos do tldr e a documentação que todo pacote do Debian carrega.

Você vai aprender
  • Ler e navegar no manual com man, inclusive as seções.
  • Usar --help para um resumo rápido e help para os comandos internos do shell.
  • Achar um comando pelo assunto com apropos e whatis.
  • Ver exemplos prontos com o tldr.
  • Encontrar o README.Debian e o histórico de mudanças de qualquer pacote.

--help: o resumo rápido

Quase todo comando aceita a opção --help, que mostra a forma de usar e as opções. No Debian em português, o texto vem traduzido:

ls
O comando sobre o qual você quer ajuda.
--help
A opção que pede o resumo de uso.
$ ls --help | head -5
Uso: ls [OPÇÃO]... [ARQUIVO]...
Lista informações sobre os ARQUIVOs (no diretório atual por padrão).
Lista as entradas em ordem alfabética se não for usada nenhuma opção -cftuvSUX
nem --sort.

O | head -5 corta a saída nas 5 primeiras linhas, porque o texto completo é longo. Para ler tudo com rolagem, use ls --help | less (saia com q).

Como ler a linha "Uso"

Na ajudaSignifica
[OPÇÃO]Entre colchetes: opcional.
...Pode repetir: várias opções, vários arquivos.
ARQUIVO em maiúsculasTroque pelo seu valor.
a|bEscolha um ou outro.
-a, --allDuas formas da mesma opção: curta e longa.

man: o manual

O man (de manual) abre a página de manual de um comando. No Debian instalado em português, o pacote manpages-pt-br já vem junto, e por isso muitas páginas aparecem traduzidas:

$ man ls
LS(1)                         Comandos de usuário                         LS(1)

NOME
       ls - lista conteúdo de diretórios

SINOPSE
       ls [OPÇÃO]... [ARQUIVO]...

DESCRIÇÃO
       Lista  informações  sobre  os  ARQUIVOs  (o diretório atual por padrão).
       Classifica as entradas em ordem alfabética  se  não  for  usada  nenhuma
       opção -cftuvSUX nem --sort.

       Argumentos  obrigatórios  para  opções  longas  também o são para opções
       curtas.

       -a, --all
              não ignora entradas começando com .
…

Navegando dentro do man

O manual abre no leitor less. As teclas principais:

TeclaO que faz
Espaço / bDesce / sobe uma página
↓ / ↑Desce / sobe uma linha
/texto EnterProcura "texto" para baixo
n / NPróxima / anterior ocorrência da busca
g / GVai para o começo / fim
hAjuda do leitor
qSai do manual
Dica: buscar uma opção

Para achar a explicação do -h do ls, abra man ls, digite /-h e aperte Enter. Repita com n até chegar na linha certa.

As seções do manual

O manual é dividido em seções numeradas. A lista abaixo vem do próprio man man, em português:

$ man man
…
       1   Comandos shell ou programas executáveis
       2   Chamadas de sistema (funções fornecidas pelo kernel)
       3   Chamadas de biblioteca (funções dentro de bibliotecas de programa)
       4   Arquivos especiais (geralmente localizados em /dev)
       5   Formatos de arquivo e convenções, ex.: /etc/passwd
       6   Jogos
       7   Miscelânea (incluindo convenções e pacotes macro),  (ex.:    man(7),
           groff(7), man-pages(7))
       8   Comandos de administração do sistema (geralmente apenas para root)
       9   Rotinas do kernel [não padrão]
…

O mesmo nome pode existir em várias seções. passwd, por exemplo, é um comando (seção 1) e também um arquivo (seção 5). O man -f lista todas:

man
O manual.
-f
Só mostra em quais seções o nome existe, com uma frase de descrição (igual ao whatis).
passwd
O nome procurado.
$ man -f passwd
passwd (5)           - arquivo de senhas              « o arquivo /etc/passwd, descrição em português
passwd (1)           - change user password           « o comando, descrição só em inglês
passwd (1ssl)        - OpenSSL application commands
$ man 5 passwd
PASSWD(5)                     Formatos de Arquivo                     PASSWD(5)

NOME
       passwd - arquivo de senhas
…

Repare que algumas descrições estão em português e outras em inglês: a tradução do manpages-pt-br cobre muitas páginas, mas não todas. Quando não há tradução, o man mostra a original em inglês.

Ler em inglês de propósito

As traduções podem estar desatualizadas em relação ao programa. Para ver a página original em inglês, use -L C:

$ man -L C ls
LS(1)                            User Commands                            LS(1)

NAME
       ls - list directory contents

help: comandos internos do shell

Alguns comandos não são programas separados: fazem parte do próprio bash. São os comandos internos (builtins), como cd, pwd e history. Para eles, a ajuda é o help. Você descobre se um comando é interno com type:

$ type cd
cd é um comando interno do shell
$ type man
man é /usr/bin/man
$ help pwd
pwd: pwd [-LP]
    Mostra o nome do diretório de trabalho atual.

    Opções:
…

A tradução da ajuda interna do bash é parcial: help pwd vem em português, mas help cd aparece em inglês.

Missão: descubra se cd, ls e echo são comandos internos do shell ou programas, usando type. Dica: type aceita vários nomes de uma vez.

apropos e whatis: procurar por assunto

Quando você não sabe o nome do comando, o apropos procura nas descrições de todas as páginas do manual:

$ apropos "list directory"
dir (1)              - list directory contents
ls (1)               - list directory contents
vdir (1)             - list directory contents
$ apropos copiar
copiar: nada apropriado.                « procure em inglês: muitas descrições não foram traduzidas

O apropos busca nas descrições que estão instaladas. Como muitas estão em inglês, procurar em inglês costuma dar mais resultado. O whatis faz o contrário: dado um nome, mostra a descrição de uma linha.

$ whatis ls
ls (1)               - lista conteúdo de diretórios

tldr: exemplos prontos

O tldr (de too long; didn't read, "longo demais, não li") mostra só os exemplos mais usados de cada comando. Não vem instalado; no Debian o programa vem no pacote tealdeer:

$ su -c 'apt install tealdeer'
Senha:
…
$ tldr --update
Successfully created cache directory path `/home/ana/.cache/tealdeer`.
Successfully updated cache.
$ tldr tar

  Ferramenta de compressão de arquivos.
  Utilizado com metodos de compressão como o de gzip ou bzip2.
  Mais informações: <https://www.gnu.org/software/tar/manual/tar.html>.

  [C]ria um arquivo compactado e o escreve para um arquivo:

      tar cf caminho/para/alvo.tar caminho/para/arquivo1 caminho/para/arquivo2 ...

  [C]ria um arquivo g[z]ip e o escreve para um arquivo:

      tar czf alvo.tar.gz caminho/para/arquivo1 caminho/para/arquivo2 ...
…

Na primeira vez, o tldr --update baixa as páginas da internet. Como o sistema está em português, os exemplos aparecem em português quando há tradução.

/usr/share/doc: a documentação de cada pacote

Este é um recurso típico do Debian: todo pacote instala uma pasta em /usr/share/doc/nome-do-pacote. Nela ficam, no mínimo, a licença (copyright) e o histórico de mudanças. Na máquina do guia, recém-instalada, já são 307 pastas.

$ ls /usr/share/doc/openssh-server/
changelog.Debian.gz  copyright  NEWS.Debian.gz  README            README.dns
changelog.gz         examples   OVERVIEW.gz     README.Debian.gz  README.tun.gz
ArquivoO que contém
README.DebianO que o Debian faz diferente do programa original. Leia este primeiro.
NEWS.DebianMudanças importantes entre versões, que podem exigir atenção.
changelog.DebianO histórico de cada versão do pacote no Debian.
changelogO histórico do programa original.
copyrightOs autores e a licença.
examples/Arquivos de configuração de exemplo.

Os arquivos terminados em .gz estão compactados. Leia com zless (com rolagem) ou zcat (direto na tela):

zcat
Mostra um arquivo .gz sem descompactá-lo no disco.

As notas do Debian sobre o servidor SSH.
| head -15
Só as 15 primeiras linhas.

Quando não funciona

"Nenhuma entrada de manual para…" 
$ man nadaexiste
Nenhuma entrada de manual para nadaexiste
$ man 9 ls
Nenhuma entrada de manual para ls na seção 9

O que aconteceu: não há página com esse nome (ou não naquela seção). Pode ser erro de digitação, um comando interno do shell (use help) ou um programa sem manual.

Como resolver: tente comando --help, help comando ou apropos.

"bash: tldr: comando não encontrado"

O que aconteceu: o tldr não vem instalado.

Como resolver: instale o pacote tealdeer (como root) e rode tldr --update.

"bash: info: comando não encontrado"

O que aconteceu: o leitor de documentação info, usado pelos manuais completos dos programas GNU, também não vem instalado por padrão.

Como resolver: instale o pacote info. Para a maioria das pessoas, o man basta.

Fiquei preso dentro do man

O que aconteceu: o manual abre num leitor que ocupa a tela toda.

Como resolver: aperte q.

Resumo

  • comando --help: resumo rápido; man comando: manual completo, muitas vezes em português.
  • No man, / procura, n repete e q sai; man 5 passwd escolhe a seção.
  • help para comandos internos (cd, pwd); type diz se o comando é interno.
  • apropos acha comandos pelo assunto; tldr (pacote tealdeer) mostra exemplos.
  • /usr/share/doc/pacote/README.Debian explica o que o Debian mudou no programa.

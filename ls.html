Debian ls

O ls (de list, "listar") mostra o que existe numa pasta. É o comando mais digitado no terminal: você vai usá-lo antes e depois de quase tudo, para conferir.

Você vai aprender
  • Ler cada coluna do ls -l.
  • Ver arquivos ocultos, tamanhos legíveis e ordenar por data ou tamanho.
  • Por que o Debian ordena "a, Área, aula1, aula10, aula2, Aula3".
  • Por que o ll não funciona no Debian e como ativá-lo.

O básico

ls
Lista a pasta atual. Pastas aparecem em azul; executáveis, em verde.
$ ls
'Área de trabalho'   Downloads    Imagens   Música    Vídeos
 Documentos          frutas.txt   Modelos   Público

Os nomes vêm em colunas, de cima para baixo. "Área de trabalho" aparece entre aspas porque tem espaços: o ls mostra o nome do jeito que você teria de digitá-lo. O espaço antes dos outros nomes só serve para alinhar.

Outra pasta

Passe o caminho como argumento. Você não precisa entrar na pasta para listá-la:

$ ls Documentos
acesso.log  notas.txt  projetos  relatorio.odt

Detalhes: -l

O -l (de long, "longo") mostra uma linha por item, com permissões, dono, tamanho e data.

ls
O programa.
-l
Formato longo.
Documentos
A pasta a listar.
$ ls -l Documentos

O Debian usa o ls do projeto GNU, que traduz a data: out 14, jan 1 2026. Em tutoriais feitos no Ubuntu 26.04 você verá Oct 14, porque lá o ls é outro programa. Os dois fazem a mesma coisa.

Arquivos ocultos: -a e -A

Arquivos cujo nome começa com ponto ficam escondidos. São, em geral, configurações, como o .bashrc. O -a (de all, "todos") mostra tudo, inclusive . (a própria pasta) e .. (a de cima). O -A mostra os ocultos sem esses dois.

$ ls -A
'Área de trabalho'   .bashrc      Downloads    Imagens   Música     Público
 .bash_history       Documentos   frutas.txt   Modelos   .profile   Vídeos

Repare que o .bashrc aparece no meio da lista, perto do "b", e não no começo. Isso tem a ver com a ordem, explicada a seguir.

A ordem: pelo idioma

O ls do Debian ordena como um dicionário em português: ignora acentos, pontos e a diferença entre maiúsculas e minúsculas. Veja uma pasta real:

$ ls
 a                   aula1    aula2   Documentos   frutas.txt   Música
'Área de trabalho'   aula10   Aula3   Downloads    Imagens
  • "Área" vem logo depois de "a", porque o acento é ignorado.
  • "Aula3" fica entre as "aula", porque maiúscula e minúscula contam como a mesma letra.
  • "aula10" vem antes de "aula2": a comparação é caractere por caractere, e "1" vem antes de "2". O ls não entende números.
Quer números na ordem certa?

Use ls -v (de version), que ordena aula1 aula2 aula10. Ou dê nomes com zeros à esquerda: aula01, aula02… aula10.

Tamanhos legíveis: -h

Com -h (de human-readable, "legível para humanos") o tamanho aparece em K, M e G, com vírgula decimal. Use junto com -l:

$ ls -lh Imagens
total 2,1M
-rw-rw-r-- 1 ana ana 2,0M ago  2 14:00 ferias.jpg      « 2,0 megabytes
-rw-rw-r-- 1 ana ana 100K set 20 10:00 perfil.png
Juntando opções

ls -l -a -h é o mesmo que ls -lah. A ordem das letras não importa.

Outras opções úteis

-d: a pasta, não o conteúdo

$ ls -ld /tmp
drwxrwxrwt 2 root root 4096 out 15 10:30 /tmp

-R: entrar nas subpastas

$ ls -R Documentos/projetos
Documentos/projetos:
backup.sh  site

Documentos/projetos/site:
index.html  style.css

-F: marcar o tipo

$ ls -F Documentos/projetos
backup.sh*  site/            « * executável, / pasta

Cadê o ll?

Muitos tutoriais usam ll como atalho para ls -l. No Debian ele vem desligado:

$ ll
bash: ll: comando não encontrado
$ type ls
ls está apelidada para `ls --color=auto'

O único apelido ativo é o que deixa o ls colorido. Os outros estão no arquivo ~/.bashrc, comentados com #:

# some more ls aliases
#alias ll='ls -l'
#alias la='ls -A'
#alias l='ls -CF'

Para ativá-los, apague o # do começo dessas linhas com um editor (nano ~/.bashrc, veja nano e vim), salve e recarregue a configuração:

$ source ~/.bashrc
$ type ll
ll está apelidada para `ls -l'

A aula .bashrc, alias, PATH mostra como criar os seus próprios apelidos.

Quando não funciona

"não foi possível acessar" 
$ ls -l documentos
ls: não foi possível acessar 'documentos': Arquivo ou diretório inexistente

O que aconteceu: o nome não existe: aqui, o "D" deveria ser maiúsculo.

Como resolver: confira com ls e use Tab para completar.

"não foi possível abrir o diretório" 
$ ls /root
ls: não foi possível abrir o diretório '/root': Permissão negada

O que aconteceu: a pasta existe, mas você não pode ler o conteúdo dela.

Como resolver: se for necessário, use su - para virar root (veja root, su e sudo).

O ls não mostrou o arquivo que eu sei que existe

O que aconteceu: o nome começa com ponto e está oculto.

Como resolver: use ls -a.

Resumo

  • ls lista nomes; ls -l mostra detalhes, com o mês em português.
  • -a mostra ocultos, -h deixa tamanhos legíveis, -t/-S/-r mudam a ordem.
  • A ordem padrão segue o idioma: ignora acentos, pontos e maiúsculas.
  • No Debian, ll vem comentado no ~/.bashrc; descomente para usar.

Debian cp e mv

O cp copia e o mv move. Mover e renomear são a mesma coisa para o Linux: os dois só mudam o endereço do arquivo. Com esses dois comandos você organiza qualquer pasta.

Você vai aprender
  • Copiar um arquivo, vários arquivos e pastas inteiras.
  • Renomear e mover com o mv.
  • Não sobrescrever nada sem querer: -i, -n e -b.
  • Ler as mensagens de erro do Debian.
Atenção antes de começar

O cp e o mv sobrescrevem sem perguntar se o destino já existir. Não há lixeira nem "desfazer". As opções desta aula existem justamente para evitar isso.

cp: copiar um arquivo

cp vem de copy, "copiar". Ele recebe primeiro a origem e depois o destino.

cp
O programa que copia.
frutas.txt
A origem: o arquivo que já existe.
frutas-backup.txt
O destino: o nome da cópia.
$ cp frutas.txt frutas-backup.txt
$ ls
'Área de trabalho'   Downloads           frutas.txt   Modelos   Público
 Documentos          frutas-backup.txt   Imagens      Música    Vídeos

Silêncio é sucesso. As duas versões ficaram lado a lado.

Copiar para dentro de uma pasta

Se o destino é uma pasta que existe, a cópia vai para dentro dela, com o mesmo nome. Com -v (verbose, "detalhado") o cp mostra o que fez:

$ cp -v frutas.txt Documentos/
'frutas.txt' -> 'Documentos/frutas.txt'          « origem -> destino
A barra no fim ajuda

Escreva Documentos/, com barra. Se a pasta não existir, o cp dá erro em vez de criar um arquivo chamado "Documentos".

Vários arquivos de uma vez

Com mais de uma origem, o último argumento tem que ser uma pasta:

$ cp -v Documentos/notas.txt Documentos/acesso.log Imagens/
'Documentos/notas.txt' -> 'Imagens/notas.txt'
'Documentos/acesso.log' -> 'Imagens/acesso.log'

Com curingas fica ainda mais curto: cp Documentos/*.txt Downloads/ copia todos os .txt (veja Curingas).

Missão: copie frutas.txt para a pasta Documentos e também para Imagens. Use -v para ver cada cópia.

Copiar pastas: -r

Sem opção, o cp recusa pastas:

$ cp Documentos/projetos copia
cp: -r não especificado; omitindo o diretório 'Documentos/projetos'

A opção -r (de recursive, "recursivo") copia a pasta e tudo o que há dentro:

cp
O programa.
-rv
-r entra nas subpastas; -v mostra cada item.
Documentos/projetos
A pasta de origem.
copia
O nome da cópia (não existia).
$ cp -rv Documentos/projetos copia
'Documentos/projetos' -> 'copia'
'Documentos/projetos/backup.sh' -> 'copia/backup.sh'
'Documentos/projetos/site' -> 'copia/site'
'Documentos/projetos/site/index.html' -> 'copia/site/index.html'
'Documentos/projetos/site/style.css' -> 'copia/site/style.css'

-a: copiar preservando tudo

O -r faz a cópia com a data de agora e com você como dono. O -a (de archive, "arquivar") é o -r que preserva datas, permissões e links. É o mais indicado para backups.

Missão: crie a pasta backup e copie para dentro dela a pasta Documentos/projetos inteira.

mv: mover e renomear

mv vem de move, "mover". A sintaxe é igual à do cp, mas a origem deixa de existir.

Renomear

Mover para um nome novo, na mesma pasta, é renomear:

$ mv -v frutas-backup.txt frutas-velho.txt
renomeado 'frutas-backup.txt' -> 'frutas-velho.txt'

Mover para outra pasta

$ mv -v frutas-velho.txt Documentos/
renomeado 'frutas-velho.txt' -> 'Documentos/frutas-velho.txt'

O Debian diz "renomeado" mesmo quando você moveu, porque internamente é a mesma operação: o arquivo ganha um endereço novo.

Pastas não precisam de -r no mv

Ao contrário do cp, o mv move pastas inteiras sem opção nenhuma: mv projetos arquivo-morto/. Mover na mesma partição é instantâneo, porque nada é copiado.

Missão: mova frutas.txt para a pasta Documentos, já com o nome novo lista-frutas.txt, num único comando.

Não sobrescrever sem querer

Se o destino já existe, cp e mv trocam o conteúdo sem avisar. Três opções protegem você:

OpçãoO que fazQuando usar
-iPergunta antes de sobrescrever (interactive)Quando você está digitando à mão
-nNunca sobrescreve, sem perguntar (no-clobber)Em scripts
-bSobrescreve, mas guarda o antigo com ~ no fim (backup)Quando você quer as duas versões
-uSó copia se a origem for mais nova (update)Para atualizar uma cópia

-i: perguntar

$ cp -i frutas.txt notas.txt
cp: sobrescrever 'notas.txt'? n                   « n mantém o original; s sobrescreve

-b: guardar uma cópia de segurança

$ cp -b -v frutas.txt notas.txt
'frutas.txt' -> 'notas.txt' (cópia de segurança: 'notas.txt~')
$ ls notas*
notas.txt  notas.txt~
Sempre perguntar

Para que o cp e o mv sempre perguntem, crie apelidos no ~/.bashrc: alias cp='cp -i' e alias mv='mv -i' (veja .bashrc, alias, PATH).

Quando não funciona

"-r não especificado; omitindo o diretório"

O que aconteceu: você tentou copiar uma pasta sem -r.

Como resolver: cp -r pasta destino, ou cp -a para preservar datas e permissões.

"não foi possível obter estado de" 
$ cp nada x
cp: não foi possível obter estado de 'nada': Arquivo ou diretório inexistente

O que aconteceu: a origem não existe. "Obter estado" é a tentativa de ler as informações do arquivo.

Como resolver: confira o nome com ls e use Tab.

"alvo … Arquivo ou diretório inexistente" 
$ cp frutas.txt notas.txt naoexiste
cp: alvo 'naoexiste': Arquivo ou diretório inexistente

O que aconteceu: com mais de uma origem, o último argumento precisa ser uma pasta que existe.

Como resolver: crie a pasta antes com mkdir. Se o alvo for um arquivo, a mensagem vira Não é um diretório.

"Permissão negada" 
$ cp frutas.txt /etc/
cp: não foi possível criar arquivo comum '/etc/frutas.txt': Permissão negada

O que aconteceu: a pasta de destino pertence ao root.

Como resolver: pense se o destino está certo. Se estiver, faça como root, com su - (veja root, su e sudo).

Mover uma pasta para dentro dela mesma 
$ mv projetos projetos/antigo
mv: não é possível mover 'projetos' para um subdiretório de si mesmo, 'projetos/antigo'

O que aconteceu: o destino fica dentro da própria origem, o que é impossível.

Como resolver: escolha um destino fora da pasta.

Sobrescrevi um arquivo sem querer

O que aconteceu: o destino já existia e o cp/mv trocou o conteúdo.

Como resolver: não há como desfazer pelo terminal. Recupere de um backup (veja Backup). Para a próxima vez, use -i, -n ou -b.

Resumo

  • cp origem destino copia; mv origem destino move ou renomeia.
  • Pastas: cp -r (ou -a para preservar tudo); o mv não precisa de opção.
  • Com várias origens, o destino é uma pasta.
  • Os dois sobrescrevem sem aviso: use -i, -n ou -b.

Debian cat, less, head, tail

No Debian, configurações, logs e anotações são arquivos de texto. Para lê-los no terminal existem quatro comandos: cat mostra tudo de uma vez, less mostra página por página, head mostra o começo e tail mostra o fim.

Você vai aprender
  • Quando usar cada um dos quatro comandos.
  • Navegar e buscar dentro do less.
  • Pegar só as primeiras ou as últimas linhas.
  • Acompanhar um arquivo ao vivo com tail -f.

cat: mostrar tudo

cat vem de concatenate, "concatenar": ele junta arquivos e mostra o resultado. Com um arquivo só, ele simplesmente mostra o conteúdo inteiro.

cat
O programa.
frutas.txt
O arquivo a mostrar.
$ cat frutas.txt
banana
maçã
laranja
banana
uva
maçã
banana

Numerar as linhas: -n

$ cat -n frutas.txt
     1	banana
     2	maçã
     3	laranja
     4	banana
     5	uva
     6	maçã
     7	banana

Juntar arquivos

Com vários nomes, o cat mostra um depois do outro, sem separação. Daí o nome:

$ cat /etc/hostname /etc/debian_version
notebook
13.7
Quando NÃO usar o cat

Em arquivos grandes, o cat despeja milhares de linhas e você só vê o fim. Para esses, use o less.

less: ler com calma

O less abre o arquivo numa tela própria e deixa você rolar para cima e para baixo. Ele não muda nada no arquivo. É o mesmo programa que o man usa para mostrar os manuais.

less
O leitor página por página (o nome é uma brincadeira com um leitor mais antigo, o more: "less is more").
/usr/share/common-licenses/GPL-3
Um arquivo grande que existe em todo Debian: o texto da licença GPL.
$ less /usr/share/common-licenses/GPL-3

Dentro do less, use estas teclas:

TeclaFaz
Espaço ou fDesce uma página
bSobe uma página
↓ ↑ ou j kDesce ou sobe uma linha
g / GVai para o começo / para o fim
/texto EnterProcura "texto" para baixo
n / NPróxima / anterior ocorrência
-N EnterLiga ou desliga os números de linha
hAjuda
qSai
O less não roda no terminal simulado

Ele ocupa a tela inteira. Pratique no seu Debian: o less vem instalado e é o paginador padrão (/usr/bin/pager aponta para ele).

head: o começo

head ("cabeça") mostra as 10 primeiras linhas. Com -n você escolhe quantas:

head
O programa.
-n 3
Quantas linhas mostrar.
frutas.txt
O arquivo.
$ head -n 3 frutas.txt
banana
maçã
laranja

A forma curta head -3 faz o mesmo. Com vários arquivos, o head põe um cabeçalho antes de cada um:

$ head -n 2 frutas.txt Documentos/acesso.log
==> frutas.txt <==
banana
maçã

==> Documentos/acesso.log <==
192.168.0.10 - - [15/Oct/2026:09:01:12] "GET / HTTP/1.1" 200
192.168.0.23 - - [15/Oct/2026:09:01:40] "GET /contato HTTP/1.1" 200

tail: o fim

tail ("cauda") mostra as últimas linhas. É o comando dos logs, porque as novidades sempre ficam no fim.

$ tail -n 2 frutas.txt
maçã
banana

A partir de uma linha: -n +N

Com um + antes do número, o tail mostra a partir daquela linha até o fim:

$ tail -n +6 frutas.txt
maçã                « linha 6 em diante
banana

Acompanhar ao vivo: -f

O -f (de follow, "seguir") mostra o fim e fica esperando: cada linha nova que entrar no arquivo aparece na hora. Para sair, aperte Ctrl+C.

$ tail -f /tmp/meu-script.log
iniciando backup
copiando Documentos
copiando Imagens        « a linha apareceu enquanto você olhava
^C
E os logs do sistema?

No Debian 13 não existe /var/log/syslog; os registros ficam no journal. O equivalente do tail -f para eles é journalctl -f (veja Logs (journalctl)).

Quando não funciona

"Arquivo ou diretório inexistente" 
$ cat nada
cat: nada: Arquivo ou diretório inexistente
$ head nada
head: não foi possível abrir 'nada' para leitura: Arquivo ou diretório inexistente

O que aconteceu: o nome está errado ou o arquivo está em outra pasta.

Como resolver: ls para conferir e Tab para completar.

"É um diretório" 
$ cat Documentos
cat: Documentos: É um diretório

O que aconteceu: esses comandos leem arquivos, não pastas.

Como resolver: para ver o que há numa pasta, use ls.

"Permissão negada" 
$ cat /etc/shadow
cat: /etc/shadow: Permissão negada

O que aconteceu: o arquivo só pode ser lido pelo root. O /etc/shadow guarda as senhas criptografadas.

Como resolver: se for mesmo necessário, leia como root: su -c 'cat /etc/shadow'.

"tail: nenhum aquivo restante" 
$ tail -f nada
tail: não foi possível abrir 'nada' para leitura: Arquivo ou diretório inexistente
tail: nenhum aquivo restante

O que aconteceu: o arquivo não existe, e o tail -f desistiu por não ter o que acompanhar. O "aquivo", sem o "r", é um erro de digitação da própria tradução do Debian.

Como resolver: confira o caminho. Se o arquivo ainda vai ser criado, use tail -F (maiúsculo), que espera ele aparecer.

A tela ficou cheia de símbolos estranhos

O que aconteceu: você usou cat num arquivo que não é texto (uma imagem, um programa).

Como resolver: digite reset e Enter, mesmo sem ver o que digita. Para saber o tipo de um arquivo antes de abrir, use file arquivo.

Resumo

  • cat mostra tudo (bom para arquivos pequenos); -n numera.
  • less lê com calma: Espaço desce, / busca, q sai.
  • head -n N mostra o começo; tail -n N, o fim; tail -f, ao vivo.
  • Logs do sistema no Debian 13: journalctl, não /var/log/syslog.

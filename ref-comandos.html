Debian Referência de Comandos

Esta página reúne os 175 comandos ensinados no guia, em ordem alfabética, com uma frase sobre cada um, o nível em que aparecem e o link para a aula completa. No fim, há uma tabela "por tarefa" para quando você sabe o que quer fazer, mas não lembra o comando.

Antes de rodar um comando que você não conhece

Pergunte ao próprio sistema o que ele é. O type diz se é um programa, um comando do shell ou um apelido; o whatis dá a descrição de uma linha do manual.

type
Comando do bash: diz o que o nome significa para o shell.
ls cd reboot
Os nomes a investigar (quantos quiser).
$ type ls cd reboot
ls está apelidada para `ls --color=auto'
cd é um comando interno do shell
bash: type: reboot: não encontrado          « está em /usr/sbin, fora do PATH da ana
$ whatis tar
tar (1)              - an archiving utility

Repare no reboot: ele existe, mas fica em /usr/sbin, que não está no PATH de um usuário comum no Debian. Veja root, su e sudo.

Comandos marcados com "instalar antes"

Não vêm num Debian recém-instalado. Instale como root: su -c "apt install nome-do-pacote".

Exercícios

1. Qual comando diz que cd é "um comando interno do shell"?

2. Você quer ver as portas abertas com o nome dos programas. O que roda?

Resumo

  • Use o índice de letras para achar um comando e o link para a aula completa.
  • Na dúvida sobre um nome, rode type e whatis antes de executar.
  • Comandos de administração pedem root: su -c "…" ou sudo, se instalado.

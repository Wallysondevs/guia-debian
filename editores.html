Debian nano e vim

Configurar um Debian quase sempre é editar um arquivo de texto. Pelo terminal, você faz isso com um editor. O Debian traz dois: o nano, simples e com os atalhos na tela, e o vi, que no Debian é uma versão reduzida do Vim.

Você vai aprender
  • Abrir, editar, salvar e sair do nano, e o que cada mensagem dele quer dizer.
  • O mínimo do vi para não ficar preso nele.
  • Qual é o editor padrão do Debian e como trocá-lo.
  • Como editar arquivos do sistema, que pertencem ao root.
Editores não rodam no terminal simulado

Eles ocupam a tela inteira. As telas desta aula foram copiadas de um Debian 13 real; pratique no seu.

Qual é o editor padrão do Debian?

O Debian escolhe o editor padrão por um sistema chamado alternatives ("alternativas"). O comando editor abre o que estiver escolhido, e programas como o crontab -e usam a mesma escolha. Numa instalação nova, o vencedor é o nano, que tem prioridade maior:

$ ls -l /usr/bin/editor /etc/alternatives/editor
lrwxrwxrwx 1 root root  9 mai  3 20:17 /etc/alternatives/editor -> /bin/nano
lrwxrwxrwx 1 root root 24 mai  3 20:17 /usr/bin/editor -> /etc/alternatives/editor

O caminho é uma corrente de atalhos: editor → /etc/alternatives/editor → /bin/nano.

nano: o editor fácil

Para abrir um arquivo, passe o nome. Se ele não existir, o nano cria quando você salvar.

nano
O editor.
frutas.txt
O arquivo a abrir.
$ nano frutas.txt

  • Primeira linha: a versão e o nome do arquivo. Quando você altera algo, aparece um * ao lado do nome.
  • Meio: o texto. Você digita normalmente e anda com as setas.
  • Mensagem entre colchetes: o que acabou de acontecer. Num arquivo que não existe, aparece [ Novo arquivo ].
  • Duas últimas linhas: os atalhos. O ^ quer dizer Ctrl: ^X é Ctrl+X.

Salvar: Ctrl+O

Ctrl+O grava (de Write Out). O nano confirma o nome no rodapé; aperte Enter para aceitar:

Escrever para o arquivo: novo.txt
^G Ajuda          M-D Formato DOS   M-A Anexar        M-B Arquivo reserva
^C Cancelar       M-M Formato Mac   M-P Pré-anexar    ^T Navegar

Depois do Enter, aparece [ Escrita 1 linha ] (ou "Escritas 7 linhas"): o arquivo foi salvo. O M- nas opções quer dizer Alt.

Sair: Ctrl+X

Se não houver nada por salvar, o nano fecha na hora. Se houver, ele pergunta:

Salvar o buffer modificado?
 S Sim
 N Não          ^C Cancelar

Aperte S para salvar (ele pede o nome, Enter confirma), N para sair perdendo as mudanças, ou Ctrl+C para voltar ao texto. "Buffer" é o texto que está aberto na memória.

O passo a passo completo

  1. nano novo.txt abre (ou cria) o arquivo.
  2. Digite o texto normalmente.
  3. Ctrl+O e Enter salvam.
  4. Ctrl+X sai.
  5. cat novo.txt confere o resultado.
$ nano novo.txt
$ cat novo.txt

Ctrl+F ou Ctrl+W?

No nano 8 (Debian 13) a busca aparece como ^F Onde está?. Em versões antigas, como a do Debian 12, ela aparecia como ^W. Se um tutorial antigo mandar usar Ctrl+W, use o que aparece no rodapé do seu nano.

vi: o mínimo para sobreviver

O vi existe em praticamente todo sistema Unix, inclusive em servidores mínimos. No Debian, o comando vi abre o vim.tiny, uma versão reduzida do Vim. O Vim completo não vem instalado:

$ ls -l /usr/bin/vi /etc/alternatives/vi
lrwxrwxrwx 1 root root 17 mai 22  2025 /etc/alternatives/vi -> /usr/bin/vim.tiny
lrwxrwxrwx 1 root root 20 mai 22  2025 /usr/bin/vi -> /etc/alternatives/vi
$ vim notas.txt
bash: vim: comando não encontrado

O vi é um editor de modos: no modo normal as teclas são comandos, e só no modo de inserção elas viram texto. Isso confunde quem abre o vi pela primeira vez. Guarde esta receita:

Quero…Digite
Começar a escreveri (de insert)
Parar de escreverEsc
Salvar e sairEsc e depois :wq Enter
Sair sem salvarEsc e depois :q! Enter
Apagar a linhaEsc e depois dd
DesfazerEsc e depois u
Preso no vi?

Aperte Esc duas vezes e digite :q! seguido de Enter. Você sai sem salvar nada. O vim.tiny do Debian mostra as mensagens em inglês, porque é compilado sem traduções.

Para aprender o Vim de verdade, o root instala o pacote completo com apt install vim.

Trocar o editor padrão

Para você: select-editor

O select-editor pergunta qual editor você prefere e guarda a escolha em ~/.selected_editor. Ela vale para programas como o crontab -e:

$ select-editor
Select an editor.  To change later, run select-editor again.
  1. /bin/nano        <---- easiest
  2. /usr/bin/vim.tiny

Choose 1-2 [1]:

Para o sistema inteiro: update-alternatives

Como root, o update-alternatives --config editor muda o editor de todos os usuários. Aperte Enter para manter o atual:

#> update-alternatives --config editor
Há 2 escolhas como alternativas de editor. (fornecendo /usr/bin/editor).

  Seleção    Caminho            Prioridade Estado
------------------------------------------------------------
* 0            /bin/nano           40        modo automático
  1            /bin/nano           40        modo manual
  2            /usr/bin/vim.tiny   15        modo manual

Pressione <enter> para manter o padrão[*] ou digite o número da seleção:

Por variável: EDITOR

Muitos programas leem a variável EDITOR. No Debian ela vem vazia; para fixá-la, ponha export EDITOR=nano no seu ~/.bashrc (veja .bashrc, alias, PATH).

Editar arquivos do sistema

Arquivos de /etc pertencem ao root. Se você abrir um deles como usuário comum, o nano abre, mas não consegue salvar. No Debian, sem sudo, há duas formas:

FormaExemploQuando usar
Um comando como rootsu -c 'nano /etc/hosts'Uma edição rápida
Sessão de rootsu -, depois nano /etc/hosts, depois exitVárias edições seguidas
sudoeditsudoedit /etc/hostsSó se o sudo estiver instalado e configurado (veja root, su e sudo)
$ su -c 'nano /etc/hosts'
Senha:
Antes de editar um arquivo do sistema

Faça uma cópia: cp /etc/hosts /etc/hosts.bak (como root). Se algo der errado, basta copiar de volta.

Quando não funciona

O nano não consegue salvar 
[ Erro ao escrever /etc/hosts: Permissão negada ]

O que aconteceu: o arquivo é do root e você abriu como usuário comum.

Como resolver: salve uma cópia na sua pasta (Ctrl+O e mude o nome para ~/hosts), saia, e copie como root: su -c 'cp ~ana/hosts /etc/hosts'. Na próxima vez, abra com su -c 'nano /etc/hosts'.

Abri o vi sem querer e não consigo sair

O que aconteceu: um programa (como crontab -e) abriu o vi, ou você digitou vi.

Como resolver: Esc, :q!, Enter. Para isso não se repetir, rode select-editor e escolha o nano.

"vim: comando não encontrado"

O que aconteceu: o Debian só instala o vim.tiny, chamado pelo comando vi.

Como resolver: use vi, ou instale o Vim completo como root: apt install vim.

O terminal "congelou" no nano

O que aconteceu: você pode ter apertado Ctrl+S, que em muitos terminais pausa a tela.

Como resolver: aperte Ctrl+Q para destravar.

Resumo

  • O editor padrão do Debian é o nano; o vi abre o vim.tiny e o Vim completo não vem instalado.
  • nano: Ctrl+O salva, Ctrl+X sai, Ctrl+F procura.
  • vi: i escreve, Esc para, :wq salva e sai, :q! sai sem salvar.
  • Troque o editor com select-editor (você) ou update-alternatives --config editor (sistema).
  • Arquivos do sistema: su -c 'nano /etc/arquivo', com uma cópia de segurança antes.
